QUICK START / 02

新手安装教程

从下载文件到成功启动，按步骤检查即可。

▣ 安装步骤

  1. 确认游戏版本查看整合包页面标注的 Minecraft 版本，例如 1.16.5 或 1.20.1。
  2. 安装对应加载器根据整合包要求安装 Forge 或 Fabric，不要混用不兼容的版本。
  3. 下载并解压（如需要）按整合包作者说明操作；压缩包、启动器整合包的安装方法可能不同。
  4. 分配合适内存并启动先关闭占用内存的软件。若崩溃，保留错误日志以便排查。
  5. 进入多人服务器只有在你拥有真实服务器地址且版本、模组匹配时，才能加入多人游戏。

▣ 常见问题

问题01

游戏启动就崩溃

核对 Java 版本、加载器版本、模组依赖，并检查崩溃报告。

问题02

进服提示版本不一致

客户端和服务器需要使用兼容的 Minecraft 版本、加载器和模组配置。

问题03

下载链接打不开

确认链接是否公开、文件是否仍然存在，以及网盘是否需要授权。

建议只下载可信来源的文件，不要运行来历不明的启动器或脚本。
